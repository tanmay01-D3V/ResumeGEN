# ResumeGEN frontend

React 19 + Vite + TypeScript + Tailwind v4 client for ResumeGEN. See the
[root README](../README.md) for setup, architecture, integration status and limitations, and
[docs/](../docs/) for the API, data model, Sheets setup, testing, demo and screenshot guides.

```bash
npm install
npm run dev        # http://localhost:5173, proxies /api to http://localhost:5050
npm run typecheck
npm run lint
npm run test
npm run build
```

Demo login: `demo@example.com` (prefilled). This is not production authentication; see
[the integration status](../README.md#integration-status).
